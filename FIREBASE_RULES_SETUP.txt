    function isAdmin() {
      return request.auth != null && request.auth.uid == "LNghcfytsiU2x627gt4iAzPFaFH3";

B) STORAGE RULES (Firebase Console > Storage > Rules)
Publish these rules. They allow public image/video/audio reads and owner-only uploads.

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    function isAdmin() {
      return request.auth != null && request.auth.uid == "LNghcfytsiU2x627gt4iAzPFaFH3";
    }
    match /profilePictures/{uid}/{fileName} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == uid
        && request.resource.size < 5 * 1024 * 1024
        && request.resource.contentType.matches('image/.*');
    }
    match /books/{bookId}/{fileName} {
      allow read: if true;
      allow write: if isAdmin()
        && request.resource.size < 300 * 1024 * 1024;
    }
  }
}

C) CORS FOR LOCAL LIVE SERVER (the browser error in the console)
A failed preflight can also happen if the bucket CORS policy does not allow your
local origin. Save the adjacent file storage-cors.json, then run ONE of these
commands from Google Cloud SDK terminal after authenticating to the Google account
that owns this Firebase project:

  gcloud storage buckets update gs://dreamwings-2777e.firebasestorage.app --cors-file=storage-cors.json

or (older SDK):
  gsutil cors set storage-cors.json gs://dreamwings-2777e.firebasestorage.app

The CORS file allows localhost and 127.0.0.1 ports 5502 and 5503 used by Live Server.
If Live Server picks another port, add that exact origin to storage-cors.json and
apply the command again. CORS is not a substitute for Firebase Storage Rules.
